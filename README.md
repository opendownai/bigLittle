# 大乐透预测（固定三个自然年数据）

*本项目仅供娱乐和研究学习。彩票开奖是随机事件，模型评估不构成中奖保证。*

## 当前数据

- 训练窗口：2024、2025、2026 三个自然年，不使用按天或按期滚动窗口
- 数据量：386 期，24001（2024-01-01）至 26084（2026-07-27）
- 数据 SHA-256：`b24321b45baa9beeb91579d56d7f44399b1c5a5b41f613490c5c2ce858079fcd`
- 完整的 2,902 期 GitHub 数据已与中国体彩官方接口逐期比对一致
- 另一份源自官方接口的 GitHub 快照对其中 2,845 期再次交叉验证

数据、来源提交和核验结果见 `data/dlt_merged.manifest.json`。

## 当前模型

- 运行设备：Apple Silicon Mac mini，动态权重 ANE 训练管线
- 架构：2 层，dim 64，hidden 128，4 heads，seq 64，vocab 48
- 参数量：85,312
- 训练：固定三年全部 386 期，从头训练 4,000 步
- checkpoint SHA-256：`13bc8a48b7ddf23aa7dac73fd5a679e6a3e5c4e524738c70a62c3cdbe015c53d`

四段各 36 期的时间顺序留出结果为 0.944、1.083、1.389、1.083
个命中，均值 1.125；50 期频率基线均值 0.958，随机理论期望 1.048。
样本量仍不足以证明模型有稳定的超随机预测能力，因此这些数字只用于模型比较。

候选号码排序器也已在相同数据上重训，但独立测试集平均命中 0.944，
低于频率基线 1.000 和随机理论期望 1.048，因此不作为默认模型。

## 使用

```bash
python3 update_dlt_data.py --check-only
python3 generate_predictions.py
```

默认预测方法是 `ane`。训练和验证命令见 `TRAINING.md`。

## 自动闭环

macOS `launchd` 每天 08:30 和 22:45 触发一次幂等任务：

1. GitHub 数据与中国体彩官方接口逐期核验后，更新固定三个自然年数据。
2. 按期号查找已经开奖的结构化预测，并在 `analysis/` 另写结果，不修改原预测。
3. 只有出现新一期且下一期预测尚不存在时，才在 Mac mini 上从头训练 ANE。
4. 将模型、训练 token、snapshot 和日志保留在本机，只记录它们的 SHA-256。
5. 在 `predictions/<期号>.json` 和 `pre/<期号>.txt` 写下一期预测。
6. 通过严格白名单提交本期数据、预测、分析与模型哈希，并推送当前分支。

安装和查看任务：

```bash
python3 automation/manage_schedule.py install
python3 automation/manage_schedule.py status
```

手工只读检查：

```bash
python3 automation/prediction_cycle.py --dry-run
```

自动提交只接受以下路径：

- `data/dlt_merged.json` 和来源清单
- `predictions/*.json`
- 以五位期号命名的 `pre/*.txt`
- `analysis/*_result.json`、`analysis/*_result.md` 和累计结果
- `models/ane_lottery_deploy.manifest.json`

如果暂存区存在白名单外文件，任务会拒绝提交。模型二进制、训练 token、
ANE snapshot 和日志均由 `.gitignore` 排除，推送失败会让本次任务报错，
下次调度会继续重试。

## 规则说明

2026 年第 26014 期起实施的新规则调整了奖级和奖金结构，但仍保留
前区 35 选 5、后区 12 选 2 的随机开奖方式。因此号码模型继续使用
2024–2026 全部数据；只有奖金、奖级或期望收益分析需要按 26014 分段。
